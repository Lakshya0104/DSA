Severity

Incidents enter a priority queue (severity, then time). Each one is assigned the idle ambulance with the shortest road travel time, found with a single reverse Dijkstra search.

Click a start point and then a destination. Dijkstra and A* run on the same query so you can compare how many nodes each one explores.

Click a road to close or reopen it. Ambulances whose route uses it re-plan with A*. A union-find pass then counts any cut-off areas.
